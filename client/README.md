# Six Tick 客户端

Flutter 3.35.7 / Dart 3.9.2，共享 iOS、Android、Windows、macOS 业务逻辑。

项目运行、测试与发布说明见 [仓库 README](../README.md)。

本地仓库和云数据始终使用不同的随机加密密钥。系统认证不可用时使用至少 12 字符的本机密码。生产构建默认拒绝 HTTP；不要将开发配置用于发布。

macOS 上已使用本机密码的仓库，可在「安全与备份 → 应用锁」启用 Touch ID。首次启用需验证现有本机密码并完成指纹认证；之后锁屏页默认提供 Touch ID，也可切换回密码。原密码不会被保存到钥匙串或移除。

Touch ID 使用独立的随机标识，将仓库密钥保存在本机数据保护钥匙串中，访问控制为 `biometryCurrentSet`，不参与 iCloud 同步。取消认证、指纹不可用或指纹集合发生变化时，可使用原密码解锁；指纹更改后需关闭再开启 Touch ID。关闭功能或删除仓库会删除对应钥匙串条目。iOS、Android 和 Windows 的现有认证方式保持不变。

macOS 真机验收（需已签名构建和录入 Touch ID 的 Mac）：使用现有密码仓库启用 Touch ID；锁定后用指纹解锁；重启应用后重复；取消弹窗后验证密码备用入口；关闭 Touch ID 后确认不再提供指纹解锁；修改系统指纹后确认旧钥匙串密钥失效，密码仍可解锁。将自动锁定设为“立即”后，再验证启用与解锁不会被系统认证弹窗打断；系统锁屏仍应立即锁定应用。
